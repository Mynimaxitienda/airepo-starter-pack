# 🚀 AIRepo Starter Pack

**Start your AI webapp in minutes, not weeks.**

AIRepo Starter Pack is a free, open-source starter pack to help developers in Latin America build AI-powered webapps faster.

No more wasting weeks on setup. Clone, configure, and build with AI Agents already integrated.

**Live Demo:** https://repostarterpack.web.app
**For:** Developers in Barranquilla, Colombia & Latin America learning to build with AI

---

## 🤔 The Problem

Many talented developers want to build with AI, but they get stuck on:
- How to structure a modern webapp?
- How to configure AI Agents?
- How to deploy fast?

AIRepo Starter Pack solves this with a ready-to-use repo.

## ✨ What You Get

- **AI Agents Included:** Pre-configured prompts and agents to help you code, document and debug.
- **Modern Stack:** React 18 + TypeScript + Vite + Tailwind CSS
- **Deploy in 1 Click:** Firebase Hosting + GitHub Actions - auto deploy on push to `main`
- **Design System:** Black & Orange Neon base, clean and fast
- **Cloud-First:** Works on any platform
